Database maintenance

  • Clean up now

    Deletes data older than the saved retention periods.

  • Compact database

    Rebuilds the file to give free space back to the disk (VACUUM). Needs free disk space about the size of the database; new data waits in memory meanwhile.

  • Empty write buffer

    Moves the write-ahead log (WAL) into the database and truncates it.

  • Check integrity

    Quick read-only consistency check of the database file.
